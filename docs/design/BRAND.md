# MacPad Brand Direction

## Working name

MacPad is a temporary working name. It must be replaced if it conflicts with an existing product or trademark.

## Direction

- Original developer-tool identity.
- Calm, precise, readable and unmistakably macOS-friendly.
- Visual metaphor: a document surface with a focused text caret.
- Avoid copying the Notepad++ two-color notepad treatment.
- Prefer a restrained blue/indigo accent that works in Light and Dark Mode.

## Asset plan

- `Assets.xcassets/AppIcon.appiconset`: app icon.
- `assets/design/logo.svg`: vector wordmark.
- `assets/design/logo-mono.svg`: monochrome logo.
- `assets/design/brand-sheet.svg`: visual reference.
- Use SF Symbols for toolbar and sidebar controls unless a custom symbol is necessary.

## Icon requirements

- Distinct silhouette at 16x16.
- Master vector source.
- Light and dark background checks.
- macOS iconset sizes generated during packaging.
- No Notepad++ name, logo or copied artwork.
