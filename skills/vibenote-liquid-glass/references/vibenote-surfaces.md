# VibeNote Surface Decisions

| Surface | Default treatment | Reason |
|---|---|---|
| Main code/text editor | Opaque/system content background | Maximum readability and stable selection/caret contrast |
| Toolbar | Native toolbar/system material; glass only when supported | Functional navigation/action layer |
| Tab strip | Native tab component; conditional glass chrome | Navigation surface, not document content |
| Folder Workspace sidebar | Sidebar/system material; conditional glass chrome | Navigation hierarchy |
| Search field/popup | Native control or transient glass surface | Short-lived action surface |
| Search Results | Standard material/opaque panel | Dense content and scanability |
| Preferences | Native window/material | Long-form settings readability |
| Inspector/Document Map | Standard material, optional controlled glass chrome | Secondary navigation without obscuring content |
