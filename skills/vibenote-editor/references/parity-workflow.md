# Parity Workflow

For every feature:

1. Find its row in `docs/parity/FEATURE_PARITY_MATRIX.md` and CSV.
2. Verify the Notepad++ manual/repository evidence.
3. Define VibeNote behavior and any macOS adaptation.
4. Implement service/model, command, UI and tests as one vertical slice.
5. Run build and relevant tests.
6. Update matrix, CSV, menu matrix if needed, implementation log and project state.

Use `PARITY_IN_PROGRESS` if any option, error, persistence, undo, shortcut or accessibility path remains incomplete.
